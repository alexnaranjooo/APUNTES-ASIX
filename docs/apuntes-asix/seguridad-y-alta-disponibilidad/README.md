# ⚙️ Seguridad y Alta Disponibilidad

## 🔒 Seguridad Informática (ASIX)

¡Bienvenido a la sección de Seguridad! Este espacio recopila la teoría fundamental, los mecanismos de protección y las estrategias de defensa para salvaguardar los sistemas informáticos frente a amenazas internas y externas.

### 📂 Índice de la Unidad

Selecciona el bloque temático que deseas consultar:

#### 🛡️ 1. Fundamentos y Mecanismos de Seguridad

* Descripción: Introducción a la ciberseguridad, distinción entre seguridad activa y pasiva, y las cuatro fases clave de los mecanismos de protección: Prevención, Detección, Restauración y Análisis Forense.

#### 🎯 2. La Tríada CID y Elementos Vulnerables

* Descripción: Estudio de la Confidencialidad, Integridad y Disponibilidad, junto con el análisis de los elementos vulnerables (hardware, software, datos, red y usuarios) y los informes de vulnerabilidades (CVE).

#### 🏢 3. Seguridad Física y Lógica (Pasiva)

* Descripción: Medidas de protección ante amenazas físicas (CPD, salas frías, sistemas SAI) y controles lógicos (listas de control de acceso, contraseñas, copias de seguridad y antimalware).

#### 🌐 4. Seguridad de Red y Control de Acceso

* Descripción: Defensa en profundidad y análisis de amenazas capa por capa del modelo OSI (desde la física hasta la de aplicación), gestión de identidades (autenticación vs. autorización) y control de acceso mediante DAC y MAC.

#### 🔍 5. Análisis Forense Informático

* Descripción: Metodología sistemática y fases para la reconstrucción de incidentes de seguridad garantizando la cadena de custodia y la preservación de evidencias digitales.

### 🛠️ Enfoque del Módulo

* Seguridad Activa: Acciones proactivas orientadas a evitar que se produzca el daño (actualizaciones, parches, control de accesos).
* Seguridad Pasiva: Medidas orientadas a minimizar el impacto una vez que el incidente o desastre ya se ha materializado (copias de respaldo, redundancia, alta disponibilidad).
* Defensa en Profundidad: Implementación de múltiples capas de seguridad superpuestas para que, si falla una barrera, el sistema siga protegido.

> 💡 _Nota: Esta documentación se actualiza de forma progresiva con casos prácticos de administración de sistemas y laboratorios de ciberseguridad._
