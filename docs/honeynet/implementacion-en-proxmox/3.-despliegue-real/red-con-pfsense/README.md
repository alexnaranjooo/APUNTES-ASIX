# Red con pfSense

pfSense es el centro de la red: separa las VLANs, decide quién habla con quién, reparte las direcciones, resuelve los nombres y publica la web hacia la red del centro.

* [pfSense: interfaces y reglas](pfsense-interfaces-y-reglas.md): las VLANs y el firewall de cada red.
* [DHCP por MAC y DNS](dhcp-por-mac-y-dns.md): direcciones fijas por MAC y resolución de `honeynet.lan`.
* [Reenvío de puertos (NAT)](reenvio-de-puertos-nat.md): cómo se publica la web por la WAN.
