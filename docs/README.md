# HOME

## Apuntes ASIX

Bienvenido a recopilación de apuntes, prácticas y recursos de **Administración de Sistemas Informáticos en Red (ASIX)** de **Alex Naranjo**.

He creado este espacio para tener todo el contenido de clase organizado y poder consultar fácilmente lo aprendido durante el ciclo.

### ¿Qué encontrarás aquí?

* 🖥️ Sistemas operativos y administración de sistemas
* 🌐 Redes y comunicaciones
* 🔐 Ciberseguridad
* 🐧 Linux
* 🗄️ Bases de datos
* 💻 Lenguajes de marcas y programación
* 🐳 Docker y virtualización
* 🌍 Servicios de red
* 📡 Configuración y administración de redes
* 📝 Prácticas, ejercicios y apuntes de clase

### Objetivo

La idea es mantener estos apuntes **organizados, actualizados y fáciles de consultar**, tanto para repasar antes de un examen como para volver a consultar algo aprendido durante el curso.

Este GitBook también sirve como una pequeña documentación personal de todo lo que voy aprendiendo en ASIX.
